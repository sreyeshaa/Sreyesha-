# Compressible Flow Calculator

A Python library and command-line tool for the one-dimensional compressible-flow relations of a
calorically perfect gas (default γ = 1.4). It was developed as a case study for the course
**Python Programming**, SRM Institute of Science & Technology, Department of Aerospace Engineering.

## 1. Project overview

When a gas moves at speeds close to or above the speed of sound, its density changes along the flow
and the incompressible approximation fails. The Mach number M = V/a decides how the flow behaves:
below Mach 1 it adjusts smoothly, above Mach 1 it adjusts through shock waves and expansion fans.
The relations that describe these effects are used in nozzle, inlet, wind-tunnel and high-speed
vehicle design, but evaluating them by hand from tables is slow and error-prone.

This project is a calculator for those relations. It started from a small public script that handled
isentropic flow, the normal shock and the Prandtl–Meyer function. We reviewed it, fixed its defects
(division by zero, no input validation, failing inverse solver, a validation routine that never
failed), and extended it into a tested library that now covers six flow models:

| Flow model | What it computes |
|---|---|
| Isentropic flow | T₀/T, p₀/p, ρ₀/ρ, area ratio A/A\*, and the inverse (Mach number from A/A\*) |
| Normal shock | M₂, p₂/p₁, ρ₂/ρ₁, T₂/T₁, p₀₂/p₀₁, entropy rise, Pitot pressure ratio, inverse relations |
| Oblique shock | θ–β–M relation, weak and strong solutions, maximum deflection angle, full downstream state |
| Prandtl–Meyer expansion | ν(M), its inverse, and expansion-fan solver with Mach-wave angles |
| Rayleigh flow | Heat addition in a constant-area duct, exit Mach number, thermal-choking detection |
| Fanno flow | Wall friction in a constant-area duct, exit Mach number, choking detection |

## 2. Project objectives

1. Review the original code, reproduce its defects, and correct them.
2. Add the standard relations a Mach-1-and-above calculator should provide: oblique shocks,
   expansion fans, inverse relations, and Rayleigh and Fanno duct flow.
3. Verify every relation against published tables (NACA Report 1135, Anderson) and against physical
   identities, using an automated test suite that anyone can re-run.
4. Provide a usable interface: a command-line tool with an interactive menu, plots, and a library
   that other Python programs can import.
5. Document the theory, design, results and limitations in a technical report.

## 4. Project structure

The project can be used in two equivalent ways.

**Option A: single-file edition** (simplest, one file contains everything)

```
compressible_flow_calculator.py   library + command-line tool + all 116 tests
```

**Option B: multi-file edition** (same code, split by purpose)

```
compressible_flow.py              numerical library (no input/output)
main.py                           command-line interface: validation, plots, menu
test_compressible_flow.py         108 library tests
test_main.py                      8 command-line tests
requirements.txt                  dependencies
figures/                          plots generated by the program
```

The commands below are written for Option B. For Option A, replace `main.py` with
`compressible_flow_calculator.py`.

## 5. How to run the program

### 5.1 Get the code

```bash
git clone https://github.com/sumniblue/Compressible_flow_calculator_Mach1.git
cd Compressible_flow_calculator_Mach1
pip install -r requirements.txt
```

### 5.2 Run everything (checks, plots, interactive menu)

```bash
python main.py
```

This runs the 16 self-validation checks against published table values, saves six plots into the
`figures/` folder, and then opens an interactive menu:

```
  1  Full summary at one Mach number
  2  Oblique shock (M1 + wedge angle theta)
  3  Prandtl-Meyer expansion (M1 + turn angle)
  4  Isentropic: Mach number from A/A*
  5  Rayleigh duct: exit Mach for T02/T01
  6  Fanno duct: exit Mach for f L/D
  7  Change gamma (currently 1.4)
  q  Quit
```

Type the number of an option, answer the prompts, and the results are printed. Invalid input
(for example a wedge angle too large for an attached shock, or a choked duct) produces a clear
message and the menu continues.

### 5.3 Command-line options

| Command | What it does |
|---|---|
| `python main.py --mach 2.5` | One-shot summary of all relations at Mach 2.5, no prompts |
| `python main.py --mach 2.5 --gamma 1.3` | Same, for a different γ |
| `python main.py --validate` | Run only the 16 table checks (exit code 0 if all pass) |
| `python main.py --plots` | Generate only the six figures into `figures/` |
| `python main.py --no-plots` | Skip figure generation |
| `python main.py --no-interactive` | Skip the interactive menu |
| `python main.py --show` | Also open plot windows (the default is to save only) |

The single-file edition also accepts `--test` to run the whole test suite.

Example (`python main.py --mach 2`):

```
--- Isentropic relations (M = 2, gamma = 1.4) ---
  T0/T = 1.8000   p0/p = 7.8244   rho0/rho = 4.3469
  A/A* = 1.6875

--- Normal shock (M1 = 2) ---
  M2 = 0.5774   p2/p1 = 4.5000   rho2/rho1 = 2.6667
  T2/T1 = 1.6875   p02/p01 = 0.7209   (s2-s1)/R = 0.3273
  Pitot p02/p1 = 5.6404
```

### 5.4 Run the tests

```bash
python -m pytest -q
```

Expected result: `116 passed`. For the single-file edition use
`python compressible_flow_calculator.py --test` or `python -m pytest compressible_flow_calculator.py -q`.

### 5.5 Use it as a library

```python
import compressible_flow as cf          # single-file edition: import compressible_flow_calculator as cf

cf.normal_shock(2.0)                              # M2, p2/p1, rho2/rho1, T2/T1, p02/p01
cf.oblique_shock(2.0, theta_deg=10)               # weak solution (beta = 39.31 deg)
cf.oblique_shock(2.0, theta_deg=10, weak=False)   # strong solution
cf.prandtl_meyer_expansion(2.0, 10)               # state after a 10-degree expansion
cf.mach_from_area_ratio(1.6875, supersonic=True)  # -> 2.0
cf.rayleigh_exit(0.3, 2.0)                        # exit Mach after doubling T0
cf.fanno_exit(0.5, 0.5)                           # exit Mach; raises ValueError if the duct chokes
```

All angles are in **degrees**. Results are returned as named tuples (for example
`cf.normal_shock(2.0).p2_p1`), and the forward functions also accept NumPy arrays. Physically
impossible requests (a normal shock at M < 1, a wedge beyond the detachment limit, a choked duct)
raise `ValueError` with an explanatory message instead of returning a wrong number.

## 6. Verification summary

- 116 automated tests pass, covering 99 % of the library's statements.
- Results match the published tables (NACA 1135 / Anderson) at several Mach numbers for every model.
- Inverse functions recover the Mach number to better than 3×10⁻¹³ relative error for M ≥ 1.001.
- A near-sonic tolerance bug found during verification was fixed and is guarded by regression tests.

## 7. Limitations

The models assume a calorically perfect gas (constant γ) and steady, one-dimensional (or locally
planar) flow. Real-gas effects at high Mach numbers, viscous boundary layers, conical shocks and
shock interactions are not covered.
